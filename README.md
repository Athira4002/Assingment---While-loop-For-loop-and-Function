## 📌 About the Assignment

This assignment focuses on fundamental Python concepts through three simple programming tasks. It provides hands-on practice with loops, control statements, and user-defined functions.

## 🚀 Programs Included

### 🎯 1. Number Guessing Game
- Generates a random number between 1 and 10.
- Allows the user a maximum of 3 attempts.
- Implements `while`, `break`, `continue`, and `else`.

### 🔢 2. Multiplication Table Generator
- Accepts a number from the user.
- Generates its multiplication table from 1 to 10.
- Uses `for` loop and `range()`.

### 📊 3. BMI Calculator
- Calculates Body Mass Index (BMI).
- Takes weight and height as user inputs.
- Uses a user-defined function with `return`.
